# PakCalc - Pakistan Finance Calculators

Free, advanced finance calculators for Pakistan: Zakat, Income Tax (FBR FY 2025-26 slabs),
Loan/EMI (with amortization schedule + compare mode), Compound Interest, Salary,
Currency Converter (PKR) and Freelancer Fee calculators - plus guides for each.

Static site (HTML/CSS/JS, no build step). Calculations run entirely in the browser.
Open `index.html` or deploy the whole folder to any static host (e.g. GitHub Pages).

Note: replace the placeholder domain `pakcalc.pk` in `sitemap.xml` and `robots.txt`
with the real domain, and `hello@pakcalc.pk` in `contact.html` with a real email.
